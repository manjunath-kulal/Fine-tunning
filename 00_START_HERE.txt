## 🎓 Technical Highlights

### Architecture
```
Base Model (Qwen2-7B)     [Frozen - not updated]
         ↓
    [LoRA Adapters]       [Only these trained - 100MB]
         ↓
   Fine-tuned Output      [Ready for inference]
```

### Training Approach
- **LoRA (Low-Rank Adaptation)**: Parameter-efficient fine-tuning
- **4-bit Quantization**: Memory optimization
- **Prompt Engineering**: Clear system/user messages
- **Multi-epoch Training**: 3 iterations over data
- **Validation Monitoring**: Best model selection

### Data Format
```json
{
  "comment_id": "COMMENT_00000",
  "commentary_text": "Gold showing strong bullish momentum...",
  "trend_label": "up"
}
```

## 💡 Usage Example

```python
from scripts.inference import TrendClassifier

# Load fine-tuned model
classifier = TrendClassifier("outputs/final_model")

# Classify a commentary
commentary = "Gold showing strong bullish momentum with price breaking above key resistance levels."
result = classifier.classify(commentary)

# Output
print(f"Trend: {result['trend_label']}")           # uptrend
print(f"Justification: {result['justification']}")
```
